# GAO Kexin

Personal website: https://gao-kexin.github.io/

Static HTML, CSS, and JavaScript. `index.html` is the homepage; the full-screen research map and interactive project demos are included in `maps/` and `demos/`.

GitHub Pages serves the root of the `main` branch. Changes to the published files are deployed automatically after pushing to `main`.

To preview locally, run `python -m http.server 8000` from this directory and open http://localhost:8000/.
